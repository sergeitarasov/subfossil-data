# Subfossil classification vault

Open this folder as an Obsidian vault. Body-part grids are generated under `canvas/baserow/`; place manually curated species/morphotype canvases under `canvas/species/`.

Each image is named after its catalogue number, which Obsidian displays on the image card. Move or copy the card itself; no separate label group is needed. Keep `runs/` image paths unchanged: canvases reference those files rather than embedding copies.

See [workflow instructions](../../scripts/README.md) in the repository for setup, Baserow selection rules and rerunning. Run the commands from the repository, not from Obsidian.

The grids show visual similarity, not validated species assignments. Review the selection report for each run before classification.
